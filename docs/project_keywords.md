# VisionGuide 핵심 키워드

컴퓨터 비전 기반 시각장애인 보조 자동 음성 안내 시스템 (EXPO-2026 캡스톤)

## 1. 인공지능

### 탐지
- **YOLOv8n** — 가볍고 빠른 객체 탐지 모델로, 기기에서 실시간 추론한다.
- **흰 지팡이 · 사람 (2클래스)** — 지팡이와 사람을 함께 탐지해 지팡이 사용자를 판별한다.
- **ROI 크롭 추론** — 관심 구역만 잘라 추론해 멀리 있는 작은 지팡이의 탐지율을 높인다.

### 경량화
- **TFLite INT8 양자화** — 모델을 8비트 정수로 줄여 Raspberry Pi에서 빠르게 돌린다.
- **Coral Edge TPU** — 전용 가속기로 추론 속도를 높인다. (컴파일본은 `v4_320`에만 있고 현행 기본 모델 `v15_320`은 CPU로 동작해 Coral에서는 검증하지 못했다.)
- **Raspberry Pi 4 실시간 추론** — 별도 서버 없이 기기 단독으로 초당 10프레임 이상을 목표로 한다.

### 데이터
- **그룹 단위 재분할** — 같은 장면의 증강본이 학습·평가에 나뉘어 들어가는 데이터 누수를 막는다.
- **유사물 네거티브** — 등산스틱·우산·목발 사진을 "지팡이 아님"으로 학습시켜 오탐을 줄인다.
- **배경 네거티브** — 지팡이가 없는 배경 사진을 학습시켜 빈 장면의 오탐을 줄인다.
- **오토 라벨링** — 기존 모델로 영상 프레임에 라벨 초안을 자동으로 붙인다.
- **라벨 검수 툴** — 자동 라벨을 사람이 확인·수정하는 웹 도구다.
- **합성 야간셋** — 낮 이미지를 어둡게 변환해 야간 성능의 회귀를 감시한다.

### 추적
- **IoU 트래커** — 프레임 간 박스 겹침으로 같은 객체에 같은 번호를 이어 붙인다.
- **재식별(되살리기)** — 잠깐 끊겼다 다시 잡힌 객체에 이전 신원을 되돌려 준다.
- **보행자 엔티티** — 사람과 지팡이를 한 쌍으로 묶어 프레임 사이에 상태를 유지한다.
- **지팡이 사용자 래치** — 한 번 지팡이 사용자로 확인되면 그 판정을 이어 간다.
- **가상 지팡이 박스** — 지팡이가 가려진 동안 사람 위치로 지팡이 위치를 추정해 판정이 끊기지 않게 한다.

### 오탐 억제
- **3중 게이트** — 정지 억제·움직임·사람 동반 세 조건을 모두 통과한 지팡이만 안내를 발동한다.
- **구조물 마스크** — 현장의 기둥·문틀 같은 고정 오탐을 박스 단위로 기억해 막는다.
- **오탐 핫스팟 → 제외구역 제안** — 오탐이 잦은 지점을 모아 제외구역 후보로 운영자에게 제안한다.

### 평가
- **실영상 벤치마크** — 정지 이미지가 아니라 실제 영상에서 안내가 발동하는지로 모델을 판정한다.
- **의사 영상** — 연속 촬영 프레임을 영상으로 복원해 평가 표본 수를 늘린다.
- **임계값 스윕** — 신뢰도 기준을 바꿔 가며 성능 변화를 한 번에 비교한다.
- **재현율/오탐 분리** — 정답 구간 안의 탐지율과 구간 밖의 오탐율을 따로 집계한다.
- **지표 차이 분석** — 정지 이미지 1위 모델이 실영상에서는 뒤처질 수 있음을 실측으로 확인했다.

### 개인정보
- **얼굴 모자이크** — 사람 박스 상단을 픽셀화해 영상에서 얼굴이 식별되지 않게 한다.
- **원본 영상 저장 비활성** — 배포 환경에서는 영상 녹화를 끄고 통계와 이벤트만 남긴다.

### 검증했으나 미채택
- **색 히스토그램 · OSNet · OpenVINO Re-ID** — 동일인 판별을 시험했으나 오합침 위험이 커서 채택하지 않고 기록으로 남겼다.

## 2. 그 외 기능

### 음성 안내
- **ROI 진입 감지** — 사용자가 지정 구역에 들어서면 해당 구역의 안내를 재생한다.
- **사람 단위 디바운스·쿨다운** — 같은 사람에게 안내가 반복되지 않게 하고, 다른 사람의 안내는 막지 않는다.
- **중복 안내 방지** — 여러 명이 동시에 진입해도 같은 안내를 한 번만 낸다.
- **순차 재생 큐** — 여러 카메라의 안내가 겹치지 않고 순서대로 나온다.
- **음소거** — 대시보드에서 재생만 끄고 탐지·기록은 유지한다.

### ROI 설정
- **폴리곤 편집** — 브라우저에서 구역을 그리고 안내 문구·오디오를 지정한다.
- **트리거/제외 구역** — 안내를 발동하는 구역과 탐지를 무시하는 구역을 구분한다.
- **핫리로드** — 설정을 저장하면 재시작 없이 2초 안에 반영된다.

### 다중 카메라
- **카메라별 독립 파이프라인** — 카메라마다 별도 스레드로 탐지·추적·안내를 처리한다.
- **CCTV 연결** — Pi 한 대에 CCTV를 연결해 카메라 2대까지 처리한다.
- **영상 회전** — 카메라 설치 방향에 맞춰 영상을 90도 단위로 돌린다.

### 관리자 대시보드
- **다중 기기 관리** — 여러 Pi를 한 화면에서 등록하고 상태를 확인한다.
- **실시간 영상 스트림** — 기기 카메라 영상을 브라우저에서 바로 본다.
- **이벤트 모니터링** — 감지·안내 이벤트를 실시간으로 확인한다.
- **원격 재시작** — 현장에 가지 않고 기기 서비스를 재시작한다.
- **영상 검증 재생** — 저장된 영상을 배포와 같은 로직으로 돌려 안내 발동 여부를 미리 확인한다.

### 통계
- **유동인구 · 지팡이 사용자** — 전체 통행자 수와 지팡이 사용자 수를 따로 집계한다.
- **시간대별/기간별** — 시간대별 분포와 일별 추이를 조회한다.
- **막대·선 차트 전환** — 같은 데이터를 막대 또는 선 그래프로 볼 수 있다.
- **중복 집계 방지** — 잠깐 가려졌다 다시 잡힌 같은 사람을 두 번 세지 않는다.

### 서버 연동
- **이벤트 전송** — 기기가 감지 이벤트를 서버로 보내고, 실패하면 보관했다가 다시 보낸다.
- **하트비트** — 기기의 생존 여부와 상태(온도·부하)를 주기적으로 알린다.
- **API Key 인증** — 기기마다 발급한 키로 서버 접근을 인증한다.
- **오프라인 단독 동작** — 네트워크가 끊겨도 탐지와 음성 안내는 기기 단독으로 계속된다.

### 하드웨어
- **GPIO** — LED·부저·냉각팬·버튼을 연결해 기기 상태를 알리고 제어한다.
- **Wi-Fi/핫스팟 전환** — 버튼 한 번으로 홈 Wi-Fi와 자체 핫스팟을 오간다.
- **블루투스 Wi-Fi 설정** — 망에 없는 기기에 휴대폰·브라우저로 Wi-Fi 정보를 전달한다.

### 품질
- **pytest 800여 개** — 핵심 로직을 자동 테스트로 고정한다.
- **프레임 루프 통합 테스트** — 탐지부터 안내·전송까지 전체 경로를 실제로 돌려 스레드 예외까지 잡는다.

## 3. 언어·프레임워크

- **언어** — Python(기기·백엔드·AI), TypeScript(프론트엔드)
- **AI** — PyTorch·Ultralytics(학습), TFLite·Coral Edge TPU(기기 추론), OpenCV·NumPy(영상 처리)
- **백엔드** — FastAPI(API 서버), SQLAlchemy·SQLite(데이터 저장), JWT(관리자 인증)
- **프론트** — React·Vite(화면), Tailwind CSS(스타일), SVG(차트)
- **기기** — Raspberry Pi 4(현장 장비), systemd(부팅 시 자동 실행), gpiozero(GPIO 제어)
