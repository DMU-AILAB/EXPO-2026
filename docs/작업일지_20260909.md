# 작업일지 — 2026-09-09

## 작업 주제

VisionGuide Pi 대시보드 **Wi-Fi 온보딩 기능** 구현 및 Pi 배포

---

## 배경

Pi를 새 장소에 설치할 때 저장된 Wi-Fi 프로필이 없으면 네트워크에 연결할 방법이 없었음.
물리 버튼으로 AP↔Station 전환은 가능했지만, 초기 Wi-Fi 자격증명 입력 수단이 부재.

---

## 구현 내용

### 1. `roi_editor/network_manager.py` (신규)
- nmcli 래퍼 모듈
- `get_status()` / `scan_networks()` / `connect_wifi()` / `switch_to_ap()`
- 3초 딜레이 메커니즘: 백그라운드 daemon 스레드로 AP→Station 전환
  - HTTP 응답 먼저 반환 → 3초 후 `nmcli connection up <SSID>` → AP 종료
- 캡티브 포털 설정/해제 (`_apply_captive_portal` / `_remove_captive_portal`)
  - dnsmasq conf 작성: `address=/#/192.168.4.1` (모든 DNS → Pi IP)
  - iptables PREROUTING: 포트 80 → 포트 5000 리다이렉트

### 2. `roi_editor/server.py` (수정)
네트워크 API 5개 추가:
- `GET /api/network/status` — 모드/SSID/IP/hostname
- `GET /api/network/scan` — 주변 Wi-Fi 목록
- `POST /api/network/connect` — 백그라운드 연결 시작 (즉시 200 반환)
- `GET /api/network/connect-result` — 연결 결과 폴링용
- `POST /api/network/ap` — AP 모드 전환

캡티브 포털 엔드포인트 추가:
- iOS: `/hotspot-detect.html`, `/library/test/success.html`
- Android/Chrome: `/generate_204`, `/gen_204`
- Windows: `/ncsi.txt`, `/connecttest.txt`
- Ubuntu: `/canonical.html`
- catch-all: host 헤더 기반으로 AP IP 외 요청 → 대시보드 리다이렉트

### 3. `roi_editor/static/index.html` (수정)
- AP 모드 amber 배너 추가 (모드==ap일 때 표시)
- 모니터링 탭에 네트워크 카드 추가 (모드 뱃지, IP, Wi-Fi 설정 패널)
- Wi-Fi 설정 패널: 스캔 → SSID 선택 → 비밀번호 입력 → 연결
- 연결 후 안내: `http://raspberrypi.local:5000` + 결과 폴링 (2초 간격)
- JS: `loadNetworkStatus()` 10초 폴링, `scanWifi()`, `connectWifi()`

### 4. `deploy/auto_ap.sh` (신규)
- 부팅 15초 후 wlan0 연결 상태 확인
- 미연결 → `VisionGuide-AP` 자동 전환 + iptables/dnsmasq 적용
- 이미 AP → iptables/dnsmasq 재적용
- Station → 캡티브 포털 규칙 제거

### 5. `deploy/visionguide-auto-ap.service` (신규)
- Type=oneshot systemd 유닛, NetworkManager 이후 실행

### 6. `deploy/visionguide-network.sudoers` (신규)
- `ailab` 유저 NOPASSWD 규칙: nmcli, iptables, pkill, tee, rm, mkdir
- 위치: `/etc/sudoers.d/visionguide-network`
- 서비스를 `User=root` 대신 `User=ailab`으로 유지하기 위해 도입

### 7. `deploy/visionguide-avahi.service` (신규)
- Avahi mDNS HTTP 서비스 광고 (`_http._tcp` 포트 5000)
- 설치 위치: `/etc/avahi/services/visionguide.service`
- 효과: `http://raspberrypi.local:5000` 자동 접근 가능

### 8. `discover.py` (신규)
- PC에서 실행하는 Pi IP 탐색 도구
- 로컬 서브넷 자동 감지 후 254개 IP 병렬 스캔 (80스레드, timeout 0.4s)
- 포트 5000 열린 IP에 `/api/network/status` 확인으로 VisionGuide 여부 검증
- 약 3~4초 내 결과 출력
- 표준 라이브러리만 사용 (별도 설치 불필요)
- 옵션: `--open` (브라우저 자동 실행), `--subnet` (서브넷 직접 지정)

### 9. `docs/wifi-onboarding-guide.md` (신규)
- Wi-Fi 온보딩 전체 기능 문서화

## 트러블슈팅 (오늘 발생한 이슈)

### `User=root` vs `User=ailab` 권한 충돌
- 최초 `User=root`로 설정 → fastapi가 `/home/ailab/.local`에만 설치되어 `ModuleNotFoundError`
- `sudo pip3 install fastapi` 시도 → 다른 Python 경로에 설치되어 서비스가 못 찾음
- **해결:** `User=ailab` 유지 + sudoers NOPASSWD 규칙으로 nmcli/iptables 권한 부여

### rsync 미설치 환경에서 배포
- `make sync-roi-editor` → rsync not found 오류
- **해결:** `scp` 직접 사용으로 개별 파일 전송

### sed 플레이스홀더 치환 실패
- PowerShell→Git Bash→SSH 체인에서 `sed -i` 따옴표 망글링
- **해결:** 로컬에서 미리 치환된 파일(`*-ailab.service`) 생성 후 SCP

### `ModuleNotFoundError: fp_hotspots`
- `DEPLOY_PY` 목록에 있으나 수동 전송 과정에서 누락
- **해결:** `scp fp_hotspots.py` 별도 전송

### Windows `python` → Microsoft Store stub (exit 49)
- **해결:** 전체 경로 `C:\Users\AILAB\anaconda3\python.exe discover.py` 사용
