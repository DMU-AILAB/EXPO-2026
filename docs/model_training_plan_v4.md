# 모델 학습 설계 v4 — 추가 촬영 없이, 가진 데이터만으로

> **진행 상태: 전부 완료 (E0·E1·E2·E3).** 결론은 **`v10_nolkc` 유지**이며,
> 기존 데이터만으로 하는 개선은 **소진됐다.** 상세는 리포트 §13·§14·§15.
>
> | 단계 | 내용 | 결과 |
> |---|---|---|
> | E0 | 평가 축 1편 → 6편 (의사 영상 복원) | 학습 0회 |
> | E1 | augC vs augB | **기각** — 배포 지점 4패 2무 (§13) |
> | E2 | pedcctv 비율 스윕 (3런) | 가설 지지, 비율 미확정 (§14) |
> | E3 | 3관측 확정 (6런) | **가설 확증, 채택 기각** (§15) |
>
> **핵심 소득**: "배포 프레이밍이 학습에서 전량 지팡이-네거티브라 confidence가 눌린다"는
> 가설이 **확증**됐다(보존율 base 23.1% → ped50 34.3%, 쌍별 8-9). 그러나 네거티브를
> 빼서 고치면 **실내(2-9)와 person recall(2-9)이 함께 무너진다** — pedcctv가 동시에
> 배포 각도의 person 표현이기 때문이다. **처방은 그 프레이밍의 지팡이 양성을 채우는
> 것**이며, 그래서 이 결과는 촬영 계획의 우선순위를 바꾼다(§15-4).

> **불변 제약**: `test2/3/4.mp4`는 평가 전용 — 학습에 넣지 않는다(제거한 누수 재발).
> EdgeTPU 컴파일은 범위 밖.

실내 도메인 갭은 추가 촬영으로만 풀리므로([`data_collection_plan.md`](data_collection_plan.md)),
이 문서는 **촬영을 기다리는 동안 기존 데이터로 얻을 수 있는 이득**만 다룬다.

## 1. 진단 — "못 찾는 것"이 아니라 "확신이 없는 것"

정지 이미지 mAP50은 0.945로 KPI(0.85)를 크게 넘는데, 실패는 배포 임계값에서만 난다
(리포트 §5-2, test1, v10 full-integer):

| conf | 지팡이 탐지 |
|---|---|
| **0.55 (`--conf` 기본값 = 배포 지점)** | **233 (28.9%)** |
| 0.25 | 610 (75.8%) |
| 0.10 | 735 (91.3%) |

목표는 mAP를 더 올리는 것이 아니라 **이 격차를 좁히는 것**이다.

### 문제가 아닌 것 (측정으로 배제)

| 후보 | 측정 | 판정 |
|---|---|---|
| 객체가 작다 | imgsz 320에서 지팡이 중앙값 50.4×58.5px. COCO small(<32²) 15.6%뿐, medium 78.5% | 아님 |
| 학습 부족 | mAP50 0.9445(81ep) → 0.9450(100ep) | 포화 |
| 과적합 | val loss 끝까지 단조 하강, patience 30 미발동 | 아님 |
| 클래스 불균형 | 사람 21,354 : 지팡이 6,767 = 3.16:1 | 심하지 않음 |
| 학습 비결정성 | 동일 args 두 런(v9_augB / v10_nolkc)이 실영상 586 vs 589 | 재현성 양호 |

## 2. E0 — 평가 축 확대 ✅ 완료 (학습 0회)

`datasets/v2/test`의 AIHub 이미지가 **연속 촬영 프레임**이었다. 결번 없는 시퀀스 5개,
417프레임이고 **5개 세션 전체가 test 전용**이라 누수가 없다(전수 확인).
`tools/eval/build_pseudo_videos.py`로 복원해 **평가 영상이 1편 → 6편이 됐다.**

복원의 본체는 **좌우 반전 정렬**이었고, 전역 DP → 방향 정렬 + 히스테리시스로 바꿔
잔여 반전을 0으로 만들었다. 상세와 한계는 리포트 §13-1.

> **축의 성격을 반드시 구분할 것** — 의사 영상은 **학습 도메인 안**이라 confidence가
> 높아 conf 0.10과 0.55 결과가 거의 같다. **트랙 지속성·게이트 동작을 재고,
> confidence 격차와 오탐은 못 잰다.** 그쪽은 `test1`~`test3`다.

## 3. E1 — augC vs augB 판정 ✅ 완료 → **기각, v10 유지** (학습 0회)

`v9_augC`가 지금과 같은 데이터(lkc 없음)로 학습됐음을 epoch 시간으로 확정해
(lkc 없는 런 34.6~34.7 s/ep vs lkc 포함 v10_v8n 36.1 s/ep) **재학습 없이** 판정했다.

**24개 조합에서 augC 우세 4 / 열세 10. 배포 지점(conf 0.55)에서 이긴 영상 0편**(4패 2무).
test1에서 통과 387 → 336, **최장 연속 474 → 290**으로 무너진다.

리포트 §3-2의 `augC 617 > augB 586`은 **test1 한 편, conf 0.25 한 점**의 산물이었고,
축을 넓히자 부호가 뒤집혔다. 증강 축은 이번 6영상 기준으로 **닫는다.**

## 4. E2 — pedcctv 비율 스윕 (가설) · 3런 · **승인 후 착수**

### 가설

`datasets/v2` train 9,971장 중 **`pedcctv` 2,753장(27.6%)** 은 실물 확인 결과
**실외 거리 CCTV 보행자**(횡단보도·인도, 224×224, 부감 고정 카메라, 이미지당 사람
중앙값 2명)다. **배포 프레이밍과 정확히 같은 장면인데 지팡이 라벨이 0개**다.
모델은 "이 프레이밍에는 지팡이가 없다"를 2,753번 배우고, 배포 현장이 그 프레이밍이다.

**전례**: `lkc` 644장이 같은 형태로 실영상 589 → 349(−41%)를 만들어 기각됐다(§4-2).
**pedcctv는 같은 형태이며 4.3배 크다.**

**사람 라벨 총량 손실은 작다** — 지팡이 이미지 6,678장 중 **99.1%가 이미 사람 라벨 보유.**

### 반론 (판정 축을 정하는 근거)

1. **총량은 남아도 분포가 바뀐다.** pedcctv는 **배포 각도의 person 표현 그 자체**이고,
   사람 동반 게이트가 **모든 트리거의 필수 조건**이라 person recall 하락은 곧 안내 실패다.
2. **FPR 미달의 주범은 person 오탐이다** — 배경 홀드아웃 conf 0.25에서 9박스 중 7이
   person, 지팡이 오탐은 2/40 = 5%(§5-3).

→ 전량 제거가 아니라 **비율 스윕**, 그리고 판정에 **person recall과 오탐을 함께** 넣는다.

### 설계

**신규 `tools/data/make_stratum_variant.py`** — 확정된 split을 유지한 채 층을 비율만큼
제외한 하드링크 변형을 만든다(재분할이 아니다). 선택은 `resplit_dataset.py`와 같은
원칙으로 **파일명 md5 기반 결정적** 방식.

| 변형 | pedcctv | train |
|---|---|---|
| (기준) v2 | 100% | 9,971 |
| v3_ped50 | 50% | 8,595 |
| v3_ped25 | 25% | 7,906 |
| v3_ped00 | 0% | 7,218 |

**`val`/`test`는 절대 건드리지 않는다**(pedcctv 587 / 602장 유지) — 건드리면 비교가
불가능해지고, 남겨둬야 person 회귀를 측정할 수 있다. 증강은 augB(v10) 고정, seed 0.

### 판정 축 4개

| 축 | 어디서 재는가 | 의미 |
|---|---|---|
| 실영상 지팡이 탐지 | **6영상 전부** | 가설의 이득 |
| **conf 0.55 대 0.25 격차** | **`test1`·`test2`·`test3`만** — 의사 영상은 in-domain이라 conf에 반응하지 않는다(§2) | **§1 격차가 좁혀지는가 = 직접 증거** |
| **person recall** | `yolo val`, test split | **사람 동반 게이트 약화 — 최대 리스크** |
| 오탐(지팡이·사람 분리) | 배경 40장 / 유사물 136장(`--classes 0`) | 반론 2 |

**판정**: 이득과 손해가 교차하는 비율을 고른다. **전 구간에서 나빠지면 가설 기각을
그대로 기록한다** — "pedcctv는 lkc와 달리 도움이 됐다"도 유효한 산출물이다.

## 5. E3 — `ped50` · `ped25` × 다중 시드 · 4런 · **진행 중**

E2에서 **선택이 아니라 필수가 됐다.** 단일 시드에서 축마다 순위가 어긋난다:

| 축 | 순위 |
|---|---|
| 통과 프레임 (실외) | ped50 > ped00 > v10 > ped25 |
| 탐지 프레임 (실내) | ped25 > v10 > ped00 > ped50 |
| 보존율 · cane R | **단조 증가** (가설대로) |

**두 후보가 서로 다른 도메인에서 이기고 있어 한쪽만 재보면 비율 질문이 그대로 남는다.**
그래서 `ped50`과 `ped25`를 각각 seed 1·2로 돌려 **둘 다 3시드**로 만든다
(seed 0은 E2 산출물). `ped00`은 person R 0.675로 이미 탈락이라 재지 않는다.

**판정**: 3시드 평균이 v10을 넘고, **person R이 세 시드 전부에서 0.87 아래로 내려가지
않을 때만** 교체한다 — 사람 동반 게이트는 모든 트리거의 필수 조건이다. 실외·실내를
따로 집계해 **한 도메인의 이득이 다른 도메인의 손실로 상쇄되는지**까지 본다.

## 6. 하지 않을 것과 이유

| 후보 | 기각 사유 |
|---|---|
| 증강 재실험 (augD/augE 등) | **E1에서 축을 닫았다**(§3) |
| imgsz 640 학습 | 원본 상한이 지팡이 416² / 사람 224². 순수 업샘플링 |
| 더 큰 백본 (yolov8s/m) | Pi FPS KPI(≥10, 현재 12.76)를 깎는다. 정지 1위가 배포 1위가 아니었다 |
| epoch 증가 | §1에서 포화 확인 |
| copy-paste 합성 증강 | 세그멘테이션 마스크가 없어 bbox 사각형 붙여넣기만 가능한데, 지팡이는 가늘어 bbox 안이 대부분 배경이라 **경계 아티팩트를 모델이 단서로 학습할 위험**이 실이득보다 크다 |
| 합성 야간 데이터 **학습** 편입 | `v2_night`는 회귀 감시용. 감마 조작본으로 학습하면 그 아티팩트를 배운다 |
| test2/3/4 활용 | **평가 전용** |

## 7. 재현 명령

```bash
# E0 — 의사 영상 5편 + video_gt.json 항목 추가 (잔여 반전이 0인지 확인할 것)
python tools/eval/build_pseudo_videos.py --split test --fps 12.76

# E0·E1 — 6영상 × 4임계값, FP32로 비교 (양자화는 최종 승자 1개만)
for M in v10_nolkc v9_augC; do
  for V in test1 pseudo_182540 pseudo_182547 pseudo_182559 pseudo_182605 pseudo_182615; do
    python tools/eval/eval_video_recall.py --backend pytorch \
      --weights-dir runs/white_cane_$M/weights \
      --video datasets/videos/$V.mp4 --imgsz 320 --preprocess letterbox \
      --cache /tmp/$V-$M.npz --thresholds 0.10 0.25 0.40 0.55
  done
done
```
