# VisionGuide 모니터링 대시보드 — 디자인 기능 명세서 (시연용 초안)

> **범위:** 시연(데모)용 초안이므로 로그인/계정/다중 사이트 관리 등은 제외하고,
> 아래 4개 화면만 정의한다.
>
> **참고 산출물:** `pdf_assets/deck/index.html` (VisionGuide 발표자료) — 파이프라인·하드웨어
> 개념을 그대로 계승한다.

---

## 0. 배경

VisionGuide 현장 장치는 다음 흐름으로 동작한다:

```
카메라 촬영 → YOLOv8n 탐지(흰지팡이·사람) → 추적(SORT) → ROI 판별
→ 디바운싱·쿨다운 → 음성 재생 · GPIO(릴레이로 기존 음성유도기 제어)
```

이 대시보드는 이 장치 한 대(또는 소수의 카메라)를 웹 브라우저에서 **보고, ROI를 수정하고,
집계를 확인하고, 녹화 영상을 다시 보는** 4가지 기능만 다룬다.

---

## 1. 공통 원칙

- **디바이스 기준:** 데스크톱 가로 화면
- **디자인 톤:** 발표자료(`pdf_assets/deck/index.html`)의 톤을 계승한다.
  - 포인트 컬러 `--accent #2C4BE0`, 정상 `--good #15875A`, 주의 `--amber #D98A2B`
  - 배경 `#FAFAF8`, 서피스 `#FFFFFF`, 텍스트 `--ink #1B1E27`, 폰트 Pretendard Variable
  - 카드형 레이아웃 · 얇은 보더(`--line #E7E5DF`) · 낮은 그림자 — `.sum-card`, `.stat-tile`, `.figure` 패턴 재사용
- **화면 전환:** 상단 탭(또는 사이드바) 4개로 "모니터링 / ROI 수정 / 통계 / 녹화" 전환. 별도 로그인 없이 진입.

---

## 2. 화면 목록

| # | 화면 | 한 줄 요약 |
|---|---|---|
| 1 | **메인 모니터링** | 카메라 실시간 영상 + 탐지 오버레이 + 핵심 지표 |
| 2 | **ROI / 음성 매핑 수정** | 카메라 화면 위에 구역을 그려 음성 안내를 지정·수정 |
| 3 | **사람수 집계 (통계)** | 유동인구·지팡이 사용자 수 그래프 시각화 |
| 4 | **영상 녹화 · 재생 (CCTV처럼)** | 녹화 시작/중지 버튼으로 남긴 클립 목록과 재생 (상시 녹화 아님) |

## 3. 공통 셸(Shell) 레이아웃

모든 화면은 아래 상단 바를 공유하고, 그 아래 영역만 화면별로 바뀐다.

```
┌──────────────────────────────────────────────────────────────────┐
│ ● VisionGuide          [ 모니터링 ][ ROI 수정 ][ 통계 ][ 녹화 ]   │  ← 높이 64px 고정
├──────────────────────────────────────────────────────────────────┤
│                                                                    │
│                         (화면별 콘텐츠 영역)                        │
│                                                                    │
└──────────────────────────────────────────────────────────────────┘
```

- 좌측: 로고 마크 + "VisionGuide" 텍스트
- 우측: 탭 4개(모니터링 / ROI 수정 / 통계 / 녹화) — 현재 탭은 `--accent` 밑줄로 표시
- 콘텐츠 영역은 좌우 76px 여백을 두고 시작 (발표자료 `.slide-inner` padding 계승)

## 4. 화면별 상세 스펙 및 레이아웃

### 화면 1. 메인 모니터링

**레이아웃 — 좌 68% (영상+이벤트) / 우 32% (상태 카드)**

```
┌────────────────────────────────────────────────┬─────────────────────┐
│  ┌───────────────┐                              │ 카메라 상태          │
│  │ ● 녹화 시작    │                              │  ● 정상    12:03:41 │
│  └───────────────┘                              ├─────────────────────┤
│           실시간 카메라 영상 (16:9)               │ 오늘 총 유동인구      │
│     [바운딩박스: 흰지팡이=빨강 / 사람=파랑]        │      128 명          │
│     [ROI 폴리곤: 반투명 --accent-soft 채움 +      ├─────────────────────┤
│      구역명 라벨]                                 │ 지팡이 사용자 감지    │
│                                                  │      7 명            │
│                                                  ├─────────────────────┤
│                                                  │ [ 안내 음성 테스트 ]  │
│                                                  │      재생 버튼        │
├────────────────────────────────────────────────┴─────────────────────┤
│ 최근 감지 이벤트                                                        │
│  시각        클래스        구역                                        │
│  14:32:10   white_cane    ROI-2 · 3번 출구                            │
│  14:31:47   person        ROI-1 · 계단 앞                              │
│  14:30:58   white_cane    ROI-3 · 화장실 앞                            │
│  (최근 8건, 스크롤 없이 고정 높이로 표시)                                │
└─────────────────────────────────────────────────────────────────────┘
```

- **영상 영역:** 실제 카메라 프레임 비율(16:9) 유지, 검은 배경(`#000`)에 영상 표시. 탐지 중인 객체마다 클래스명 + 신뢰도(%) 라벨을 박스 위에 작게 표시
- **녹화 시작/중지 버튼 (영상 좌상단 오버레이):** 상시 녹화가 아니라 이 버튼을 눌러야만 녹화가 시작되는 수동 방식.
  - 평상시: 회색 배경 + "● 녹화 시작"
  - 클릭하면 즉시 녹화 시작 → 버튼이 "■ 녹화 중지" (빨간 배경, 점 깜빡임 애니메이션) + 경과 시간(`00:00` 부터 카운트업)으로 전환
  - 다시 클릭하면 녹화 종료 → 해당 구간이 클립으로 저장되어 화면 4(영상 녹화·재생) 목록 맨 위에 즉시 추가
- **상태 카드 3종(우측 세로 스택):** 카드 간 12px 간격, 각 카드는 발표자료 `.stat-tile` 스타일(흰 배경, 얇은 보더) 그대로 사용. 숫자는 32~36px 굵게, 라벨은 13px 회색
- **카메라 상태 배지:** 정상=`--good` 점 + "정상", 오프라인="주의"색 점 + "연결 끊김 · mm:ss 전"
- **하단 이벤트 리스트:** 표 형태 3열(시각/클래스/구역), 최신순 정렬, 8건 고정 높이(넘치면 스크롤)

### 화면 2. ROI / 음성 매핑 수정

**레이아웃 — 좌 68% (편집 캔버스) / 우 32% (ROI 목록 + 속성 폼)**

```
┌────────────────────────────────────────────────┬─────────────────────┐
│ [ + 새 구역 그리기 ]                             │ ROI 목록             │
│                                                  │  ▸ ROI-1 계단 앞      │
│                                                  │  ▸ ROI-2 3번 출구 (선택)│
│         카메라 정지 프레임 위 편집 캔버스           │  ▸ ROI-3 화장실 앞    │
│    (폴리곤 꼭짓점 드래그로 모양 수정,               ├─────────────────────┤
│     빈 곳 드래그로 새 폴리곤 그리기)                 │ 선택한 구역: ROI-2    │
│                                                  │  구역명                │
│                                                  │  [ 3번 출구        ]  │
│                                                  │  음성 안내 문구        │
│                                                  │  [ "3번 출구 앞입니다" ]│
│                                                  │  활성 여부 [●켜짐]      │
│                                                  │                       │
│                                                  │  [ 삭제 ]   [ 저장 ]  │
└────────────────────────────────────────────────┴─────────────────────┘
```

- **편집 캔버스:** 화면 1과 동일한 카메라 프레임을 배경으로 사용(정지 프레임 또는 저프레임 라이브). ROI는 반투명 `--accent-soft` 채움 + `--accent` 테두리 폴리곤, 선택된 ROI만 테두리를 굵게(3px) 강조
- **상단 툴바:** "+ 새 구역 그리기" 버튼 클릭 → 캔버스가 그리기 모드로 전환(커서 변경), 드래그로 사각형/폴리곤 생성
- **우측 ROI 목록:** 클릭 시 해당 폴리곤이 캔버스에서 강조되고 하단 속성 폼에 값 로드
- **속성 폼:** 구역명(텍스트), 음성 안내 문구(텍스트), 활성 여부(토글 스위치) 3개 필드만 — 시연 범위이므로 디바운싱/쿨다운 등 세부 옵션은 제외
- **저장 버튼 클릭 시:** "현재 설정을 덮어씁니다" 확인 모달 → 확인 시 저장 후 목록에 반영

### 화면 3. 사람수 집계 (그래프 시각화)

**레이아웃 — 상단 필터, 지표 카드 3열 가로 배치, 그래프 2단 세로 배치**

```
┌─────────────────────────────────────────────────────────────────────┐
│ 기간: [ 오늘 ]  [ 7일 ]  [ 30일 ]                                     │
│                                                                       │
│ ┌───────────────────┐  ┌───────────────────┐  ┌───────────────────┐ │
│ │ 총 유동인구         │  │ 지팡이 사용자 수    │  │ 지팡이 사용자 비율  │ │
│ │     482 명          │  │     34 명           │  │     7.1 %          │ │
│ └───────────────────┘  └───────────────────┘  └───────────────────┘ │
│                                                                       │
│ 시간대별 유동인구 (0시~24시)                                          │
│ ┌───────────────────────────────────────────────────────────────┐   │
│ │                    ╭╮                              ╭╮          │   │
│ │      ╭╮      ╭─────╯╰──╮                    ╭──────╯╰───╮      │   │
│ │  ────╯╰──────╯          ╰────────────────────╯            ╰──  │   │
│ │  0   3   6   9   12   15   18   21   24 (시)                    │   │
│ └───────────────────────────────────────────────────────────────┘   │
│                                                                       │
│ 구역(ROI)별 집계                                                      │
│ ┌───────────────────────────────────────────────────────────────┐   │
│ │  ROI-1 계단 앞    ████████████████████ 210                      │   │
│ │  ROI-2 3번 출구   ██████████████ 150                            │   │
│ │  ROI-3 화장실 앞  ███████████ 122                               │   │
│ └───────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

- **기간 필터:** 탭 형태 3개(오늘/7일/30일), 선택된 탭만 `--accent` 배경 + 흰 텍스트
- **지표 카드 3열:** 동일 너비로 가로 배치, 발표자료 `.sum-card` 스타일 재사용(흰 배경 + 보더 + 그림자)
- **시계열 그래프:** 꺾은선 그래프, X축은 0~24시(3시간 간격 눈금), Y축은 유동인구 수. 라인 색상 `--accent`, 영역 아래 옅은 그라데이션 채움
- **ROI별 집계:** 수평 막대 그래프, 막대 색상 `--good`, 막대 옆에 정확한 수치 표기. ROI 이름 순서는 유동인구 많은 순 정렬

### 화면 4. 영상 녹화 · 재생 (CCTV처럼, 수동 녹화)

> 상시 녹화가 아니다. 화면 1의 "● 녹화 시작" 버튼을 눌러 시작하고 "■ 녹화 중지"를 눌러
> 끝낸 구간만 클립으로 남는다. 이 화면은 그렇게 만들어진 클립을 모아 보고 재생하는 화면이다.

**레이아웃 — 좌 32% (클립 목록) / 우 68% (재생 화면)**

```
┌─────────────────────┬─────────────────────────────────────────────┐
│ 날짜: [2026-07-28 ▾] │                                               │
├─────────────────────┤                                               │
│ [썸네일] 14:32 · 12s │                                               │
│  수동 녹화            │             선택한 클립 재생 화면              │
├─────────────────────┤            (영상 플레이어 + 재생바)             │
│ [썸네일] 13:58 · 9s  │                                               │
│  수동 녹화            │                                               │
├─────────────────────┤                                               │
│ [썸네일] 13:41 · 15s │  ▶ ────────────●───────────  00:07 / 00:12   │
│  수동 녹화            │                                               │
├─────────────────────┤                              [ 다운로드 ]      │
│ ...                  │                                               │
└─────────────────────┴─────────────────────────────────────────────┘
```

- **좌측 클립 목록:** 날짜 선택 드롭다운 상단 고정, 그 아래 클립 카드가 세로로 나열(썸네일 + 녹화 시작 시각 + 길이). 클립은 전부 화면 1 버튼으로 사람이 직접 시작·종료한 구간이므로 자동/이벤트 트리거 구분은 없음. 클릭 시 우측 플레이어에 로드되고 해당 카드가 `--accent` 테두리로 선택 표시
- **우측 재생 화면:** 검은 배경 위 비디오, 하단에 표준 재생 컨트롤(재생/일시정지, 재생바, 현재시각/전체길이), 우측 하단에 다운로드 버튼
- **목록이 비어있을 때:** "아직 녹화된 영상이 없습니다 — 모니터링 화면에서 녹화를 시작하세요" 안내 문구 + 화면 1로 이동하는 버튼

## 5. 공통 컴포넌트

| 컴포넌트 | 용도 |
|---|---|
| 상태 배지 | 정상/오프라인 표시 (정상=`--good`, 오프라인/경고=`--amber`) |
| ROI 오버레이 캔버스 | 화면 1(읽기 전용)·2(편집 가능)에서 공유 |
| 통계 그래프(꺾은선/막대) | 발표자료 `.stat-tile`, `.results-table` 톤 계승 |
| 녹화 시작/중지 버튼 | 화면 1 영상 위 오버레이 — 클릭으로 수동 시작·종료, 녹화 중엔 빨간 배경 + 경과시간 표시 |
| 비디오 플레이어 | 녹화 재생 (발표자료 `.video-thumb`/`.demo-video` 패턴 재사용) |
